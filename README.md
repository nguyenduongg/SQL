# Olist E-commerce Data Analysis Project
1. Introduction:
Dự án phân tích dữ liệu thương mại điện tử Olist (Brazil) để tìm ra các insight về doanh thu, khách hàng và vận hành.

2. Database Schema:
Dưới đây là sơ đồ quan hệ (ERD) của hệ thống dữ liệu:
![Olist ER Diagram](./ER.png)
3. Key Analysis & SQL Queries
Các phân tích chính thực hiện trong dự án:
- **Revenue Analysis:** Tổng doanh thu và tăng trưởng theo tháng.
- **Customer Insights:** Top các khu vực có lượng khách hàng lớn nhất.
- **Product Performance:** Danh mục sản phẩm bán chạy và điểm đánh giá (Reviews).
